# Known platform limitations

Honest list of things the platforms do not allow, and what Dijital Asistan does instead. Nothing here is
faked in the UI.

| Area | Limitation | What we do |
| --- | --- | --- |
| **iOS notification stream** | iOS provides no API for a third-party app to read other apps' notifications (no `NotificationListenerService` equivalent). | "Telefon Bildirimleri" (Android Notification Intelligence) exists only on Android. On iOS the settings row, permission screen and pipeline are not rendered at all (`Platform.OS` guard + module returns `supported: false`). Life events on iOS come from mail and Universal Capture (Share Extension) only. |
| **iOS Time Sensitive / Critical alerts** | Critical alerts require a special Apple entitlement; Time Sensitive needs the `com.apple.developer.usernotifications.time-sensitive` entitlement approved at build time. | Push payloads use the default interruption level. The server only sets `interruptionLevel: 'time-sensitive'` when the `TIME_SENSITIVE_ENTITLEMENT=true` flag is set after the entitlement is granted. |
| **On-device speech recognition** | Expo SDK 57 has no first-party on-device STT module. | Voice input records audio (expo-audio) and transcribes through the server STT adapter when `STT_PROVIDER` is configured. Without it, the Voice screen offers "Yazarak sor" (type instead). The community module `expo-speech-recognition` can be added as an optional dependency (documented in `src/services/speech.ts`). |
| **Device TTS seeking** | `expo-speech` cannot seek inside an utterance. | The device-TTS briefing player implements ±15 s by restarting the current chapter from the estimated sentence offset (150 wpm model). Server TTS (when configured) supports true seeking. |
| **Background execution** | iOS `BGTaskScheduler` decides when background refresh runs (often hours apart); Android Doze restricts background work. | Freshness comes from server push (briefings, critical items) and widget timelines refreshed by the server. Background sync (`expo-background-task`) is best-effort. |
| **Widgets** | Widget UI runs in a separate process with no network; lock-screen widgets render in vibrant/accented modes. | Widgets read a snapshot written by the app (App Group / encrypted cache) and refresh via timelines; content respects lock-screen privacy (counts only in `generic` mode). |
| **Android widgets (expo-widgets 57)** | `expo-widgets` renders iOS WidgetKit layouts from the shared `createWidget` definitions; its Android (Glance) renderer in SDK 57 registers the widget names/sizes (2×2, 4×2) but does not yet render the JSX layout. | The same widget definitions are registered for Android so the provider, sizes and deep links are in place; until the Glance renderer ships, Android widgets show the snapshot's title/count text only. |
| **Apple Calendar write** | EventKit writes require full calendar access; iOS 17+ separates write-only vs full access. | Read uses full access; writes happen only after an approval and only for device-calendar accounts. If access is write-only, reads are unavailable and the account shows "Bağlantı sınırlı". |
| **Microsoft token revocation** | Microsoft Graph has no server-side API to revoke a single app's refresh token. | Disconnect deletes our stored credentials and shows the link to `https://account.live.com/consent/Manage` so the user can revoke the app. Google revocation is done server-side via the revoke endpoint. |
| **Gmail push (Pub/Sub)** | Requires a Google Cloud Pub/Sub topic and domain-verified push endpoint; `watch` expires every 7 days. | Optional. Without `GOOGLE_PUBSUB_TOPIC`, Gmail sync polls (`sync-poll` cron every 10 min, 2 min for accounts with activity). Watches are renewed by the `renew-subscriptions` cron when configured. |
| **Microsoft Graph subscriptions** | Mail subscriptions expire after ≤ 3 days and require a public HTTPS validation endpoint. | Optional; polling fallback identical to Gmail. |
| **RevenueCat trials** | A free trial only exists if the store product defines an introductory offer. | The paywall shows "7 Gün Ücretsiz" only when the fetched package declares an intro offer; otherwise the CTA is "Pro'ya Geç". Prices come from the store; design copy prices are a display fallback when the store is unavailable. |
| **Share Extension memory** | iOS share extensions have a ~120 MB memory limit and no network. | Shared items are written to the App Group container and processed by the main app after the deep-link handoff (expo-share-intent). Files > 25 MB are rejected with a clear message. |
| **Android 14+ exact alarms** | `SCHEDULE_EXACT_ALARM` may be denied by the user. | Local reminders use inexact scheduling when exact alarms are unavailable; server push remains the primary channel. |
| **Kotlin/Swift compilation** | This repository's CI does not build native binaries. | Native code (NotificationListener module, config plugins) is validated by `expo prebuild`/`expo config` in CI and must be compiled by EAS Build (see docs/DEPLOYMENT.md). |
