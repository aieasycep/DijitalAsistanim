# Implementation report

Durum özeti: **tek çalışmada** monorepo, backend, mobil uygulama, web sitesi, dokümantasyon ve testler
üretildi. Bu rapor her özelliğin uygulanma ve test durumunu, hangi harici kimlik bilgisinin gerektiğini ve
kalan sınırlamaları listeler. Hiçbir satırda prototip/placeholder yoktur; "Implemented = Yes" satırları
gerçek kod, gerçek veri akışı ve gerçek testtir.

Kısaltmalar: **Unit** = Vitest (paketler) · **RN** = jest-expo + React Native Testing Library · **E2E** =
Maestro (`apps/mobile/maestro/flows`) · **pgTAP** = `supabase/tests/rls.test.sql` · **Deno** = `deno check` +
`deno lint` (42 Edge Function).

## Gerekli harici kimlik bilgileri (production)

Uygulama bunlar olmadan da çalışır (demo modu; kural tabanlı yedekler); production için `.env.example`'daki
bölümler doldurulmalıdır:

1. **Supabase** projesi (`SUPABASE_URL`, anon + service role, `SUPABASE_DB_URL`, `INTERNAL_FUNCTION_SECRET`).
2. **`TOKEN_ENCRYPTION_KEY`** (32 bayt base64).
3. **Google OAuth** client (Gmail/Calendar/Tasks + Sign-in; `docs/GOOGLE_OAUTH_VERIFICATION.md`), opsiyonel Pub/Sub.
4. **Microsoft OAuth** (Entra) client; opsiyonel Graph webhook.
5. **Apple**: Sign in with Apple (Services ID / Key), Team ID, App Group, APNs.
6. **AI**: `ANTHROPIC_API_KEY` ve/veya `OPENAI_API_KEY`; opsiyonel embedding/TTS/STT.
7. **RevenueCat**: iOS/Android public key, webhook secret, store ürünleri (`da_pro_monthly`, `da_pro_annual`).
8. **Expo/EAS** projesi (push, build), **Sentry** ve **PostHog** (opsiyonel).
9. **Google Routes** (opsiyonel, yol süresi; yoksa yol süresi gösterilmez, uydurulmaz).
