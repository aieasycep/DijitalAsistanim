# App Store & Google Play checklist

## Identity
- [ ] Bundle id `com.dijitalasistan.app` / package `com.dijitalasistan.app` registered; App Group `group.com.dijitalasistan.app`.
- [ ] App name "Dijital Asistan", subtitle "Bugün bilmen gerekenleri, sen sormadan söyler."
- [ ] Icons: `apps/mobile/assets/icon.png` (1024), Android adaptive foreground + monochrome (generated by `scripts/generate-app-assets.mjs`).
- [ ] Screenshots (6) from the marketing spec: Today briefing · "83 mail. Gerçekten önemli olan 4." · Meeting Prep · "Kim senden cevap bekliyor?" · Smart planning · "Dijital hayatına sor." — capture from a device in demo mode (`EXPO_PUBLIC_DATA_MODE=demo`).

## iOS (App Store Connect)
- [ ] Capabilities: Sign in with Apple, Push Notifications, App Groups, Associated Domains (`applinks:dijitalasistan.app`), Background Modes (audio, fetch, remote-notification, processing).
- [ ] Privacy nutrition labels match `ios.privacyManifests` (email, messages, crash data, product interaction; none used for tracking).
- [ ] Usage strings (calendar, reminders, contacts, microphone, speech, camera, photos) — Turkish + English (`assets/locales`).
- [ ] Export compliance: `ITSAppUsesNonExemptEncryption = false`.
- [ ] Sign in with Apple offered whenever third-party sign-in is offered (guideline 4.8) — yes.
- [ ] In-app purchase: products `da_pro_monthly`, `da_pro_annual` created, priced (199 TL / 1.490 TL suggested), intro offer (7-day trial) optional; paywall shows restore, terms, privacy, manage subscription (guideline 3.1.2).
- [ ] Account deletion available in-app (guideline 5.1.1(v)) — Ayarlar → Gizlilik ve Güvenlik → Hesabımı Sil.
- [ ] Review notes: demo account (email OTP) or demo mode build; explain that mail sending requires user approval; mention Share Extension and widgets.
- [ ] Widget extension and Share Extension targets included in the archive (EAS handles targets; check credentials list shows exactly the expected extensions).

## Android (Play Console)
- [ ] Data safety form: collects email address, emails/messages, calendar events, crash logs, app interactions; encrypted in transit; user can request deletion; not shared for advertising.
- [ ] Sensitive permission declarations: `BIND_NOTIFICATION_LISTENER_SERVICE` (Notification Intelligence, opt-in, Android only — provide the demo video), `READ_CALENDAR/WRITE_CALENDAR`, `RECORD_AUDIO`, `READ_CONTACTS`, `POST_NOTIFICATIONS`, `SCHEDULE_EXACT_ALARM` (justify: user-set reminders).
- [ ] Target SDK 36, app bundle, Play App Signing; `assetlinks.json` served with the upload-key & Play signing SHA-256.
- [ ] Subscriptions: base plans monthly/annual, optional free trial offer; Play Billing via RevenueCat.
- [ ] Account deletion URL: `https://dijitalasistan.app/data-deletion`.

## Both
- [ ] Privacy policy & terms live: `/privacy`, `/terms` (legal review completed — the drafts are marked in code).
- [ ] Support URL `/support`, support email configured (`SUPPORT_EMAIL`).
- [ ] Google OAuth verification submitted (docs/GOOGLE_OAUTH_VERIFICATION.md); Microsoft app registration set to production.
- [ ] Sentry release created with source maps (EAS + `@sentry/react-native/expo` plugin).
- [ ] Maestro critical flows (A–L) pass on the release candidate in demo mode; manual pass with real Gmail + Google Calendar.
- [ ] Dark mode and Dynamic Type / font scaling verified on Today, Briefing, Flow, Plan, Meeting Prep, Assistant, Settings.
- [ ] Localization: Turkish default, English complete (`packages/i18n` test enforces key parity).
