# Mobile route & testID contract

Single source of truth for expo-router routes, the DataSource calls each screen makes, and the
`testID`s that Maestro flows (apps/mobile/maestro/flows) rely on. Screens live in `app/`; feature
components in `src/features/<area>/`; every interactive element must do something real.

Conventions

- testIDs are kebab-case, prefixed by screen: `today-hero-cta`, `email-action-reply`.
- Every list item: `<screen>-item-<index>` plus a semantic id where useful (`priority-card-<insightId>`).
- All copy from `@da/i18n` keys (react-i18next `useTranslation`). No hard-coded Turkish in screens.
- Write actions (send mail, calendar create/update, task/reminder/commitment create) ALWAYS go through
  `ds.approvals.createApproval(...)` then the Approval sheet/screen — never executed directly.
- Pro-gated features call `useEntitlement().gate(feature, context)` before navigating.
- Offline: screens render cached data (TanStack Query persisted via encrypted MMKV) and show `OfflineBanner`.

## Cross-cutting components (src/features)

- `features/today/*` (HeroBriefingCard, PrioritySection, InsightMenuSheet ("Neden önemli?", "Önemli değil", "Bunu daha sık göster", "Bu kişiyi VIP yap", "Bunu takip etme", "Kaynağı Gör")).
- `features/approvals/useApprovalFlow.ts` — `requestApproval(req) → opens /approvals/[id]` helper used by every write action.
- `features/reminders/useReminderSheet.ts` — opens `/reminder` with target params.
- `features/insights/useInsightActions.ts` — maps `InsightAction.kind` → navigation/approval/handoff (reply→/email/[id]/reply, prepare→/meeting/[id]/prep, remind→reminder sheet, add_to_calendar→calendar_create approval, follow_up→/followups draft, track/check_in/open_link→handoff, plan→task_create approval, postpone→commitment postpone, complete→resolveInsight, see_options→/conflict/[id], view_source→source detail).
- `features/source/openSource.ts` — SourceRef → route (gmail/outlook → /email/[id]; calendar → event; meeting_note → /meeting/[id]/post; capture → /capture?id; life → /life/[id]).
